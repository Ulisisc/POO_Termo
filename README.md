#POO_Termo

**El objetivo de este proyecto es mostrar un ejemplo básico de Programación Orientada a Objetos y a su vez,
demostrar cómo se pueden aplicar los conceptos básicos de clase, atributos, constructores, métodos e 
instanciación de objetos en un caso sencillo (un termo)

#Conceptos aplicados
- **Clase: Termo**
- **Atributos: color, capacidad, contenido**
- **Constructor: __init__
- **Métodos: llenar(), beber()**
- **Instanciación: mi_termo**
  
## Ejecución
Para correr el programa, escribe en la terminal:

```bash
python POO_Termo.py
